# ComfyUI-Slider2D (Nodes 2.0 Compatible)

A clean, minimalist 2D coordinate/aspect slider node designed for [ComfyUI](https://github.com/comfyanonymous/ComfyUI), featuring full support for the modern **Nodes 2.0** interface.

It allows you to visually select image dimensions (`width` × `height`) on an interactive grid pad without cluttering the canvas with unnecessary sliders.

## Features

- **Full Nodes 2.0 Support:** Built with a custom DOM widget to prevent canvas disappearing issues in modern ComfyUI releases.
- **Minimalist Canvas:** Clean 2D grid pad with live dimension tags next to output sockets.
- **Configurable Range:** Parameters (`min_size`, `max_size`, `step`) are accessible via the standard node Properties panel.
